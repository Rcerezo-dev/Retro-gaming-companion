Rutas ?

Opciones para acceder a la consola Android desde Windows:
A) SD card en lector USB → letra de unidad (F:\) — recomendado
B) Termux + SFTP en la consola → accesible por red (\\192.168.1.x\share)
C) WinFsp + MTPDrive → monta el MTP como unidad (herramienta gratuita)
⚠ La ruta MTP de Windows no es compatible con acceso por ruta de carpeta.

▶ Cómo usar Retro Vault
Primera vez: configura las rutas en el panel de arriba y pulsa Guardar rutas. La Carpeta del ordenador es donde viven tus ROMs y saves en el PC. La consola solo es necesaria si quieres escanear o copiar archivos de la consola. Si tienes una base de datos de juegos (DAT de No-Intro / Redump), colócala en catalogs/ para poder Identificar.
① Scan
Activa los checkboxes de qué escanear y pulsa Scan. Se calcula la huella (SHA1/MD5) de cada ROM y se indexa en la base de datos local.
Usa Quick para solo actualizar el inventario sin calcular huellas.
② Identificar
Pulsa Identificar (catálogos). Cada ROM se compara contra la base de datos de juegos (DAT de No-Intro y Redump) para obtener su título canónico, región y revisión.
③ Organizar
Ve a Organizar para previsualizar los renombrados. Elige qué incluir en el nombre (región, revisión…) y revisa antes de tocar ningún archivo.
Los saves se renombran junto al ROM automáticamente.
④ Aplicar
Pulsa Aplicar renombrado cuando estés conforme. El rename es atómico: si algo falla a mitad, todo vuelve al estado anterior.
Después, usa Cable Sync para volcar los cambios a la consola.
