📱 Configurar Anbernic

Sigue estos pasos para que los saves se sincronicen solos entre tu PC y la Anbernic. Solo necesitas escribir una URL en el navegador de la consola — el resto son botones.

1
Abre el navegador en la Anbernic y escribe esta dirección

La Anbernic y el PC deben estar en la misma red WiFi. Escribe exactamente esta dirección en el navegador de la consola:

Detectando…

Al abrir esta URL en la Anbernic aparecerá automáticamente una guía de instalación con todos los botones de descarga.

── O descarga desde este PC y pasa los APKs a la Anbernic por cable o tarjeta SD ──

2
Instalar F-Droid
Tienda de apps necesaria para instalar Termux. Permite actualizaciones automáticas.

Descarga el APK y cópialo a la Anbernic (cable USB o tarjeta SD).
En la Anbernic: abre el APK → permite instalar de fuentes desconocidas → instala.

⬇ Descargar F-Droid.apk ℹ Más info
3
Instalar Termux
Terminal Linux para Android. Necesario para ejecutar el script de sync. No instales desde la Play Store — usa F-Droid o el APK de abajo.

Con F-Droid ya instalado: abre F-Droid → busca Termux → instala.
O descarga el APK directamente desde GitHub:

⬇ Descargar Termux APK ℹ En F-Droid
4
Instalar Termux:Boot (recomendado)
Hace que el sync se ejecute automáticamente cada vez que enciendes la Anbernic.

Instala igual que Termux. Después: ábrelo una vez para activarlo.

⬇ Descargar Termux:Boot APK ℹ En F-Droid
5
Ejecutar el script de configuración
Abre Termux en la Anbernic y ejecuta un único comando. Instala rclone, descarga la config del PC y programa el sync automático.

Abre Termux → toca la pantalla para que aparezca el teclado virtual → escribe o pega:

Cargando…
⬇ Descargar .sh
Consejo teclado Anbernic: en Termux, mantén pulsado en la pantalla → aparece un menú → Pegar.
Si habías copiado la URL desde el PC mediante ADB, el portapapeles ya está listo.

✅ Después del setup

  • El script crea ~/retrovault-sync.sh — ejécutalo cuando quieras sincronizar manualmente
  • Con Termux:Boot, el sync corre automáticamente al encender la consola
  • Los saves van al cloud (rclone) o a la carpeta de Dropbox/OneDrive del dispositivo
  • Si algo falla: abre Termux, ejecuta ~/retrovault-sync.sh para ver el error
