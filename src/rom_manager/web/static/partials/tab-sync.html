Configuración de rclone

Comprueba si tienes Dropbox/OneDrive instalado o si rclone está configurado.

Comprobando…
Abre un terminal con rclone config para añadir Dropbox, Google Drive, etc.
📋 Instrucciones para configurar Dropbox
  1. Pulsa Configurar nuevo remote… arriba para abrir el terminal.
  2. Escribe n (New remote) y pulsa Enter.
  3. Nombre: escribe dropbox y pulsa Enter.
  4. Tipo: escribe 13 (Dropbox) y pulsa Enter.
  5. En las preguntas de App Key y Secret pulsa Enter (dejar en blanco = usar app pública).
  6. Responde n a "Edit advanced config".
  7. Responde y a "Use auto config" — se abrirá el navegador para autorizar.
  8. Tras autorizar, responde y para guardar y q para salir.
  9. Pulsa Cargar estado para ver el nuevo remote en el selector.
📋 Instrucciones para configurar Google Drive
  1. Pulsa Configurar nuevo remote… arriba para abrir el terminal.
  2. Escribe n (New remote) y pulsa Enter.
  3. Nombre: escribe gdrive y pulsa Enter.
  4. Tipo: busca drive en la lista (Google Drive) y escribe su número.
  5. En las preguntas de Client ID y Client Secret pulsa Enter (dejar en blanco = usar app pública de rclone).
  6. Scope: escribe 1 (acceso completo a Google Drive).
  7. En "root_folder_id" y "service_account_file" pulsa Enter para dejar en blanco.
  8. Responde n a "Edit advanced config".
  9. Responde y a "Use auto config" — se abrirá el navegador para autorizar con tu cuenta de Google.
  10. Tras autorizar, responde n a "Configure this as a Shared Drive" (salvo que uses una Shared Drive).
  11. Responde y para guardar y q para salir.
  12. Pulsa Cargar estado para ver el nuevo remote en el selector.
Saves + states guarda sync.saves_remote = <remote><ruta>/saves y sync.states_remote = <remote><ruta>/states — la opción recomendada. Remote único guarda solo sync.remote = <remote><ruta> (modo legado, sin separar states).
