#### scripts/download-tools.ps1 (nuevo)

Script PowerShell que descarga automáticamente en `tools/`:

- **adb** desde Android Platform Tools de Google

- Idempotente: omite herramientas ya presentes
- Limpieza automática de temporales aunque falle

### feat(cli): wizard interactivo para init-config

**Problema:** `rommgr init-config` solo volcaba la plantilla TOML. El usuario tenía que editarla manualmente.

**Solución:** `src/rom_manager/wizard.py` — wizard interactivo paso a paso:

1. **Biblioteca de ROMs** — detecta rutas comunes (`D:\ROMs`, `E:\ROMs`, `~/ROMs`, `~/Documents/ROMs`)
2. **Herramientas** — detecta `chdman`, `adb` y `rclone` en `tools/` o PATH; si rclone no está, lo pregunta
3. **ScreenScraper** — usuario + contraseña con `getpass` (no se muestra en pantalla)
4. **RetroAchievements** — API key + usuario
5. **Cloud Sync** — detecta emuladores instalados (RetroArch, DuckStation, PCSX2, PPSSPP, Dolphin) en rutas estándar de Windows; pregunta cuáles añadir y el remote rclone base

Genera `config.toml` limpio con solo las secciones rellenadas; las vacías quedan comentadas.
Si `config.toml` ya existe, pregunta antes de sobreescribir.

**Archivos:**
- `src/rom_manager/wizard.py` — nuevo módulo
- `src/rom_manager/cli.py` — handler `init-config` reemplazado por `run_wizard()`; eliminado import `_CONFIG_TOML_TEMPLATE` (ya no usado)
