### Bloque 1 — DB-FIX-3: Borrar columnas deprecated · ~20 min

Columnas identificadas como muertas en el schema:
- `games.status` — `NOT NULL DEFAULT 'scanned'`, never read/written (comentario en schema)
- `games.library_path` — never used (comentario en schema, también en `_GAMES_MIGRATIONS`)
- `assets.game_id` — never written by `upsert_asset()` (comentario en `_ASSETS_MIGRATIONS`)

SQLite 3.35+ soporta `ALTER TABLE ... DROP COLUMN` (Python 3.12 → SQLite 3.39+, OK).
Restricciones: no se puede borrar PK, UNIQUE, FK destino ni última columna. Las tres son seguras.

Subtareas:
- [ ] Eliminar `status` y `library_path` del `CREATE TABLE games` en `SCHEMA_STATEMENTS`
- [ ] Eliminar `("library_path", "TEXT")` de `_GAMES_MIGRATIONS`
- [ ] Eliminar `("game_id", "INTEGER")` de `_ASSETS_MIGRATIONS`
- [ ] Añadir `_drop_deprecated_columns(cursor)` que hace `DROP COLUMN IF EXISTS` para las tres
  (con comprobación previa via `PRAGMA table_info` para compatibilidad)
- [ ] Llamar desde `initialize_database()`
- [ ] Tests: verificar que las columnas no existen tras inicializar

### Bloque 5 — NEW-1 (parcial): Aplicador de patches IPS · ~1 h

IPS es el formato más común para ROM hacks y traducciones. BPS/UPS después.
El inbox ya acepta ZIPs — si hay un `.ips` dentro, hay que poder aplicarlo al ROM base.

Subtareas:
- [ ] `patch_applier.py`: `apply_ips(rom_path, patch_path, output_path)` — parser IPS puro
  (magic `PATCH`, records `[3-byte offset][2-byte size][data]`, end `EOF`). Stdlib puro, ~40 líneas.
  Incluye soporte IPS32 (offsets 4-byte) para ROMs >16 MB.
- [ ] `GET /api/patches/list` — busca `.ips`/`.bps`/`.ups` en inbox dir; devuelve
  `[{filename, size_bytes, ext}]`.
- [ ] `POST /api/patches/apply` body `{patch_path, rom_path}` — aplica el patch y guarda
  en `<rom_stem>_patched.<ext>`; registra en `file_operations`. Solo IPS en esta entrega.
- [ ] Botón "Aplicar patch" en tab Herramientas o en detalle de juego.
- [ ] Tests: `test_ips_applier.py` con patch sintético (a/b).

### Bloque 6 — NEW-4 (visor save states) · ~1.5 h (si hay tiempo)

RetroArch `.state` = `RARCH` header (16 bytes) + payload comprimido con zlib.
El thumbnail PNG va embebido en el payload como trocito independiente.
Extracción: buscar `PNG\x89` signature dentro del payload descomprimido.

Subtareas:
- [ ] `state_reader.py`: `extract_thumbnail(state_path) -> bytes | None` — abre el `.state`,
  descomprime zlib, busca la firma PNG `b'\x89PNG'`, extrae hasta `IEND`. Stdlib puro.
- [ ] `GET /api/state-thumbnail/<path_encoded>` — devuelve el PNG o 404.
- [ ] Panel "Save States" en detalle de juego: grid de thumbnails con fecha de modificación.
