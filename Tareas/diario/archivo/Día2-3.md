## Bloque A — Gestión de conflictos en el planner ✅ COMPLETADO

**Motivación:** `rommgr apply` puede intentar renombrar dos ROMs distintas al mismo nombre destino (por ejemplo, dos dumps de la misma región). Sin un resolver, la segunda sobrescribiría a la primera silenciosamente.

### A1. `planner/conflict_resolver.py` ✅

Nuevo módulo con función:
```python
def resolve(ops: list[RenameOperation]) -> list[RenameOperation]:
    ...
```

Lógica:
- Detectar colisiones: dos `RenameOperation` con el mismo `target_path`
- Primera estrategia: marcar ambas como `status = "conflict"` y dejarlas fuera del apply
- Registrar cada conflicto en la tabla `file_operations` con `operation_type = "conflict"`
- Opcional: si el usuario pasa `--keep-both`, añadir sufijo `_1`, `_2` al nombre destino

Integrar en `planner/operation_planner.py` antes de devolver el plan.

### A2. CLI `rommgr plan` — mostrar conflictos ✅

Añadir al resumen del plan:
```
Pendientes:    4 101
Ya correctos:    312
Conflictos:        8   ← nuevo
```

Listar los conflictos con sus rutas para que el usuario sepa qué revisar.

### A3. Tests ✅

- Dos ROMs que mapean al mismo nombre → ambas marcadas `conflict`
- `--keep-both` genera sufijos únicos
- Sin colisiones → behavior inalterado

## Bloque E — Documentación Android ✅ COMPLETADO

### E1. `docs/android-sync.md` ✅ (guardado en `Tareas/Guia-Termux-Anbernic.md`)

Guía de configuración para el lado Anbernic RG 556:

**Opción A — Termux + rclone** (más control):
1. Instalar Termux desde F-Droid
2. `pkg install rclone`
3. `rclone config` apuntando al mismo remote que el PC
4. Script `~/sync-saves.sh` que sincroniza `/storage/emulated/0/RetroArch/saves/` y `.../states/`
5. Automatizar con Termux:Boot

**Opción B — FolderSync Pro** (más fácil):
1. Instalar FolderSync desde Play Store
2. Par de sync: `/storage/emulated/0/RetroArch/saves/` ↔ `Dropbox:/RetroArch/saves`
3. Sync automático por WiFi cada 15 min

Incluir:
- Rutas exactas de RetroArch Android para saves y states
- Política de conflicto equivalente a la del PC (mtime más reciente gana)
- Aviso sobre archivos bloqueados si RetroArch está abierto
