filtro `_wanted()` en el daemon reconoce ambas categorías.

#### 4. B7-4 — Inbox: ordenar resultados por plataforma

Los resultados del análisis de carpeta (Inbox) ahora se ordenan por plataforma antes de renderizarlos,
con los archivos `unknown` al final. Centinela `'\xff'` como clave de sort para plataforma nula.

```javascript
const sortedFiles = [...(d.files || [])].sort((a, b) => {
    const pa = a.platform_guess || '\xff';
    const pb = b.platform_guess || '\xff';
    if (pa !== pb) return pa < pb ? -1 : 1;
    return a.name.localeCompare(b.name);
});
```

#### 5. B7-5 — ZIP extractor: proteger ROMs de MAME/arcade

Añadido `_ARCADE_FOLDER_NAMES` en `zip_extractor.py`; si el ZIP está dentro de una carpeta con
nombre arcade (`mame`, `arcade`, `fbneo`, `fba`, `neogeo`…), se omite con mensaje claro.

#### 15. Organización en subcarpetas para ROMs multi-fichero

Los juegos de plataformas de disco se reorganizan en subcarpetas al ejecutar "Aplicar renombres":

```
psx/Crash Bandicoot.cue           →  psx/Crash Bandicoot (USA)/Crash Bandicoot (USA).cue
psx/Crash Bandicoot (Track 1).bin    psx/Crash Bandicoot (USA)/Crash Bandicoot (Track 1).bin
```

| Fichero | Cambio |
|---------|--------|
| `operation_planner.py` | `_DISC_SUBFOLDER_PLATFORMS = {"psx","saturn","ps2","dreamcast","gamecube","wii"}`. Target = `platform_dir/stem/filename`. `already_correct` usa `source == target` |
| `file_renamer.py` | `move_disc_set_to_subfolder()`: mueve CUE o GDI + tracks + saves. Rollback atómico |
| `chd_converter.py` | `parse_tracks_from_gdi()`: parsea formato GDI de Dreamcast |
| `server.py` | `_handle_apply`: dispatch `.cue`/`.gdi` → `move_disc_set_to_subfolder`; `mkdir(parents=True)` para el resto |

| Plataforma | Formato | Tratamiento |
|---|---|---|
| PSX / Saturn | `.cue` + N×`.bin` | Mueve CUE + tracks |
| Dreamcast | `.gdi` + N×`.bin`/`.raw` | Parsea GDI, mueve todo |
| PS2 / GC / Wii | `.iso`/`.chd`/`.rvz` (único) | Solo mkdir + move |
