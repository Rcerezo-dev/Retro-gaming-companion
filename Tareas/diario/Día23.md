## Bugs críticos del Roadmap

### B2 / 0A — Batch run completo en Tools

El botón "Ejecutar todo" solo lanza ZIPs, CHD y Health Check. Faltan:
Scan → Match → Health Check → Orphan Finder → ZIP → CHD → Scraper → RA Check

- [ ] Añadir checkboxes para cada tool al batch run
- [ ] Respetar orden lógico y esperar resultado de cada uno antes del siguiente
- [ ] Aplicar el selector de contexto (PC / Android) donde corresponda

### B3 / 0B — Bibliotecas PC y Android iguales

Ahora solo se sincronizan saves. Las ROMs pueden divergir sin que la app lo detecte.

- [ ] `GET /api/library-diff` — comparar qué juegos hay en PC pero no en Android y viceversa
- [ ] Pantalla "Comparador de bibliotecas" con lista de diferencias
- [ ] `POST /api/sync-roms` — copiar ROMs faltantes en cada lado (ADB o filesystem)
- [ ] Verificación post-sync: re-comparar y confirmar que ambas listas son iguales
- [ ] Política de conflictos para ROMs: si el mismo juego tiene SHA1 distinto en cada lado → mostrar al usuario, no decidir solo
