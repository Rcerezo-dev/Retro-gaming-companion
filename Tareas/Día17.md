## Trabajo realizado

### S35-1 — Modo claro/oscuro con variables CSS

Refactorización completa de `app.css` para usar CSS custom properties. Añadido toggle en
el header y panel "Apariencia" en Settings.

**Estrategia:** Variables CSS en `:root` (oscuro) y `[data-theme="light"]` (claro).
Los ~103 estilos inline en `frontend.py` se cubren con overrides `!important` en CSS
dirigidos a los patrones más frecuentes (`#1e1e2e`, `#0f0f0f`, `color:#888`, etc.),
evitando una reescritura masiva de HTML.

| Elemento | Cambio |
|---|---|
| `app.css` | Reescrito con ~70 variables CSS (`--bg`, `--bg-panel`, `--accent`, etc.) |
| `app.css` | Bloque `[data-theme="light"]` con paleta clara completa |
| `app.css` | Overrides `!important` para estilos inline de `frontend.py` |
| `app.css` | Badges, plataformas, .rpt-stat recoloreados en modo claro |
| `app.js` | `_applyTheme()`, `setTheme()`, `toggleTheme()` + persistencia `localStorage` |
| `app.js` | Init: aplica tema guardado en `DOMContentLoaded` |
| `frontend.py` | Botón `&#x263D; Oscuro` en header con `onclick="toggleTheme()"` |
| `frontend.py` | Panel "Apariencia" en Settings con botones Oscuro/Claro |
| `frontend.py` | Input búsqueda global: inline styles → `var(--bg-input)` etc. |
