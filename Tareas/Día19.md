## Trabajo realizado

### BUG-A — Sidebar tapado por el game panel overlay
- `showTab()` no cerraba el panel de juego al cambiar de tab
- El overlay (`z-index: 8000`, `inset: 0`) se quedaba abierto cubriendo el sidebar
- Fix: `closeGamePanel()` al inicio de `showTab()` si el overlay está abierto

### BUG-B — Eliminación de duplicados silenciosa
- `_handle_delete_all_duplicates` ignoraba `OSError` sin informar al usuario
- Fix: loggear el error + devolver `errors[]` en el JSON + mostrarlo en el toast del frontend

### BUG-C — Inbox dejaba archivos duplicados sin limpiar
- Cuando `dest_file.exists()`, el archivo fuente quedaba en el inbox y en la BD
- Fix: `source_file.unlink()` + `repository.delete_game(game_id)` cuando el destino ya existe

### BUG-D — Panel "Estado del sistema" en Settings
- Nuevo endpoint `GET /api/system-status` — agrega chdman, adb, rclone, RA API key, catálogos DAT, biblioteca
- Nueva sección "Estado del sistema" en Settings con indicadores ✓/✗ en grid 2 columnas
- `loadSystemStatus()` llamado automáticamente al abrir Settings

### BUG-E — Auto-detección de carpeta cloud local
- Nuevo endpoint `GET /api/detect-cloud-folder` — lee `%LOCALAPPDATA%\Dropbox\info.json`, `%OneDrive%`, ruta Google Drive
- Botón "Detectar carpeta local" en el panel rclone de Settings
- Si se detecta Dropbox/OneDrive instalado → muestra lista con botón "Usar esta carpeta" que rellena el input de ruta

### Auto RA-check tras scan
- Extraída lógica RA check a `_start_ra_check_bg(api_key)` en `make_handler()`
- `_handle_ra_check` refactorizado para usar el helper (sin código duplicado)
- Al finalizar un scan exitoso y no cancelado: si `config.ra_api_key` está configurado, se lanza RA check automáticamente en background

### S39-3 + S39-4 — Tray icon + Inicio automático con Windows

- `src/rom_manager/utils/tray_icon.py` — módulo Win32 completo (ctypes, sin dependencias externas)
  - `TrayIcon` con `start()` / `stop()` / `set_status()` / `show_balloon()`
  - Menú contextual: Abrir Retro Vault · Sync ahora · Inicio automático toggle · Salir
  - Doble clic en el icono → abre el navegador
  - Toast de bienvenida 1.5s tras registrar el icono
  - `get_autostart_status()` / `set_autostart()` vía `winreg` (HKCU\...\Run)
  - `_default_launch_cmd()` detecta si está frozen (PyInstaller) o corriendo como script
- `serve()` en `server.py` — nuevo parámetro `tray: bool = False`; lanza `TrayIcon` en hilo daemon, callback sync usa las fuentes de `config.sync_sources`, callback quit hace `httpd.shutdown()`
- `cli.py` — `--tray` flag en `rommgr serve`
- `GET /api/autostart-status` → `{"enabled": bool, "tray_running": bool}`
- `POST /api/autostart-toggle` → activa o desactiva la entrada en el registro de Windows
- `frontend.py` — panel "Inicio automático con Windows" dinámico con badge de estado y botón toggle (reemplaza las instrucciones manuales)
- `app.js` — `loadAutostart()` + `toggleAutostart()` + hook en `showTab('settings')`

**Uso:**
```
rommgr serve --tray          # arranca servidor + icono en bandeja
rommgr serve --tray --host 0.0.0.0   # accesible desde la consola también
```

### S40 — Auto-configuración consola Android
- `GET /api/anbernic-setup.sh` — genera script shell personalizado con IP y remote rclone reales del usuario
  - Opción A: instala rclone vía `pkg install rclone`, descarga config del PC desde `/api/rclone-export-config`, crea `~/retrovault-sync.sh`
  - Opción B: detecta si Dropbox/OneDrive Android está en `/storage/emulated/0/Dropbox`, crea `~/retrovault-cloud-sync.sh` con rsync
  - Termux:Boot: escribe `~/.termux/boot/retrovault-sync.sh` para auto-sync al arrancar
- `GET /api/rclone-export-config` — sirve el fichero rclone.conf del PC (para que Termux lo descargue)
- Panel "Configurar consola" en Settings: QR + instrucciones 2 pasos + botones copiar URL / descargar .sh
- Detección User-Agent Android: si el dispositivo abre el servidor, muestra overlay `#android-detected-panel` con comando curl listo para copiar
